# Sikkerhetspolicy for kaupet_open

Finner du en sårbarhet i kaupet_open, **ikke åpne en offentlig issue eller
pull request med detaljer**. Meld den privat.

## Rapportere en sårbarhet

**Mottaker:** open@kaupet.no

**Reservekontakt:** [privat rapportering via GitHub Security
Advisories](https://github.com/Kaupet/kaupet_open/security/advisories/new).
Bruk reservekanalen hvis e-posten ikke besvares innen 72 timer.

Ta med så mye som mulig av følgende:

- Beskrivelse av sårbarheten
- Steg for å reprodusere
- Potensielt omfang og påvirkning
- Eventuelle forslag til løsning

## Hva du kan forvente

- **Innen 72 timer:** bekreftelse på at rapporten er mottatt.
- **Innen 7 dager:** første vurdering av alvorlighetsgrad og en plan for
  håndtering.
- **Når sårbarheten er fikset:** kreditt i release-notatene (hvis du ønsker
  det), etter koordinert offentliggjøring.

## Koordinert retting

Detaljer, regresjonstester og beskrivelser som avslører feilen
offentliggjøres først når rettingen er publisert. Installasjonseiere
informeres om nødvendige tiltak.

## Bidrag

Rettinger og andre bidrag sendes som pull request til dette repoet etter
[CONTRIBUTING.md](CONTRIBUTING.md). Alle bidrag gjennomgås før de slås sammen;
det skjer ingen automatisk sammenslåing.

## Versjoner

Bare siste versjon på `main` mottar sikkerhetsoppdateringer; det finnes ingen
LTS-grener.
